
# ShopNest - DevOps E-Commerce Project

A sample e-commerce web application built with Python and Flask.

## Features
- Product listing
- Product search
- Shopping cart
- Sample checkout
- Health check API
- Product API

## Technologies
- Python
- Flask
- HTML
- CSS
- Git
- GitHub
- Docker
- GitHub Actions
- AWS

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://localhost:5000

## Run tests

```bash
pytest -v
```

## Health check

http://localhost:5000/health

## Products API

http://localhost:5000/api/products
